# Homelab

Laboratorio personal orientado al aprendizaje de **Administración de Sistemas**, **Linux**, **Windows Server**, **Docker** y **Ciberseguridad** mediante proyectos prácticos documentados.

El objetivo de este repositorio es desarrollar un entorno de laboratorio que permita adquirir experiencia en tecnologías utilizadas habitualmente en entornos profesionales.

---

# Objetivos

- Aprender Administración de Sistemas mediante proyectos reales.
- Documentar cada proyecto utilizando Markdown.
- Aplicar buenas prácticas de documentación y control de versiones con Git.
- Construir un portfolio técnico para demostrar conocimientos y evolución.

---

# Tecnologías

- Ubuntu Server
- Windows Server
- Oracle VirtualBox
- Docker
- Git
